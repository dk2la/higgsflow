# Preset catalogs are fetched live from the API, not baked into the catalog

Unlike Models, Presets are not in the docs: `llms-full.txt` names only the authenticated list endpoints (`GET /v1/text2image/soul-styles` and `/soul-styles/v2`, `GET /models/higgsfield/genjutsu/restyle/v1.0/presets`, the paginated `GET /marketing-studio/image/presets`) and one illustrative id, and says to always use the current list because hidden or withdrawn Presets fail only after the Request is accepted. So `higgs presets list` and `--preset` call these endpoints with the key every time, and nothing is stored in `catalog.json` or cached in the config dir: one extra `GET` per command is cheap next to the Request it guards, and a stale cache would turn a clear "unknown Preset" error before submitting into a failed Request after it. The cost is that browsing Presets needs a key and the network; should that hurt (or the lists turn out slow), a cache in the config dir refreshed by `presets list` can be added on top, as long as `--preset` still falls back to a live lookup for a name it does not know.
